# V1R.program

Persoonlijke portfolio website van **Ven1x** met een neon-gaming / black thema.

🌐 **Live:** https://ven1x-cloud.github.io/V1R.program/

## Stack
- Pure HTML · CSS · JavaScript (geen frameworks)
- Google Fonts: Orbitron + Share Tech Mono
- Hosted via GitHub Pages

## Secties
- **Hero** — Glitch-animatie + floating particles
- **Over mij** — Bio + status
- **Skills** — Animated skill bars
- **Projecten** — Project cards
- **Contact** — Contactformulier + socials

## GitHub Pages
Ga naar **Settings → Pages → Source → Deploy from branch → `main` / `/ (root)`** om de site live te zetten.
