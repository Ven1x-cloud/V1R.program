# V1R.program – Persoonlijke Portfolio Website

Een moderne, responsieve portfolio website voor **Ven1x**, gebouwd met vanilla HTML, CSS en JavaScript. Geen frameworks of dependencies vereist.

## 🚀 Functies

- **Hero-sectie** met getypte animatie
- **Over mij** sectie
- **Skills** overzicht
- **Projecten** kaarten
- **Contactformulier** met client-side validatie
- Scroll-reveal animaties
- Mobiel-vriendelijk (hamburger menu)
- Donker thema

## 📁 Structuur

```
V1R.program/
├── index.html        # Hoofd HTML-bestand
├── css/
│   └── style.css     # Alle styling
└── js/
    └── main.js       # Interactiviteit
```

## 🛠️ Gebruik

Open `index.html` in je browser – geen build-stap nodig.

Om de website live te zetten, zet je het op **GitHub Pages**:  
`Settings → Pages → Branch: main → / (root) → Save`
